# Fantasy Football Draft Tool

A modern, responsive, and interactive Fantasy Football Draft Board for the 2026 season.

## Features

- **Interactive Draft Board:** A comprehensive list of the top 300 players (PPR) with ADP, Positional Rank, Team, Bye Week, Strength of Schedule (SoS), Tiers, and ESPN Value.
- **Player Management:** Easily mark players as "Drafted" to hide or strike them out, or add them to "My Team" to build your roster in real-time.
- **Search & Filter:** Quickly find players by name using the search box, and toggle visibility of already drafted players.
- **ESPN Ultimate Cheat Sheet Integration:** Visual indicators next to player names for expert tags (e.g., Karabell's Do Not Draft, Schefter's Picks, Late-Round Fliers, etc.).
- **Draft Strategy Calculator:** Built-in tool to calculate optimal draft strategies based on league format (PPR, Half-PPR, Standard), league size (8-14 teams), and your specific draft spot.
- **Customization:** Sort columns by clicking on their headers and toggle between Light and Dark modes for optimal viewing comfort during long drafts.
- **My Team Panel:** A floating widget that keeps track of the players you've drafted.

## Usage

Simply open `index.html` in your favorite web browser to start using the tool. No backend server is required as all functionality is handled client-side via JavaScript.
